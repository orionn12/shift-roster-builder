# シフト勤務表ビルダー 仕様書

## 概要

CP-SAT ソルバー（Google OR-Tools）を使って勤務表を自動生成するツール。
フロントエンド（React/TypeScript/Vite）が条件を組み立て、バックエンド（Python/FastAPI）が解を探索して返す。

---

## 起動方法

```bash
# フロントエンド（ポート 5173）
npm run dev

# バックエンド（ポート 8000、別ターミナル）
cd backend
uvicorn app:app --reload
```

テスト（バックエンド単体）:
```bash
cd backend
python test_runner.py
```

## ハンバーガーメニュー各セクション

### 1. 自動勤務設定

**目的:** 自動作成時に、各シフトが1日に何人必要かを曜日種別ごとに設定する。

**対象シフト:**
「勤務区分」セクションで「自動」チェックが付いているシフトのみが自動作成の対象になる。
「自動」チェックが付いていないシフトは、特定日・固定・手動入力以外では一切使われない。
「自動」チェックは勤務区分が持つステータスであり、自動勤務設定セクション自体にはチェック項目はない。

**設定内容:**
- 平日 / 土 / 日 / 祝 の4種別ごとに必要人数（整数）を入力
- 区分（区分設定）を複数紐付け可能（後述）

**ソルバーへの影響:**
`weekdayNeed` / `saturdayNeed` / `sundayNeed` / `holidayNeed` としてバックエンドに送信。
毎日・各シフトで「その日に出勤している人数 ≥ 必要人数」が強制される。

---

### 2. 特定日

**目的:** 特定の日付だけ特定シフトの必要人数を通常と変えたい場合に上書き設定する。

**設定内容:**
- 日付（1〜31）・シフト・人数の組み合わせを複数登録可能
- 区分の紐付けも可能（自動勤務設定と同様）

**ソルバーへの影響:**
`dateNeed` としてバックエンドに送信。通常の必要人数より特定日設定が優先される。

---

### 3. 固定

**目的:** 特定のメンバーの出勤日を、すべて指定のシフトに固定する。

**設定内容:**
- メンバー（1名）と固定シフトの組み合わせを1行に登録。複数メンバーの一括登録はできない
- 土日祝を含め、勤務日となる日はすべて指定のシフトが入る
- 休日（OFF）にするかどうかは禁止設定で管理する

**ソルバーへの影響:**
`fixedDateShifts`（日付ごとの割り当て）としてバックエンドに送信。
該当者の対象日は必ずそのシフトが割り当てられる（ハード制約）。

---

### 4. 禁止設定

**目的:** 特定メンバーに対して「この曜日はこのシフトを入れない」などの制限を設ける。

**3ケースの動作:**
| 曜日 | シフト | 動作 |
|---|---|---|
| 指定あり | 指定あり | その曜日にそのシフトを禁止 |
| 指定あり | なし（-） | その曜日を完全に休みにする |
| なし（-） | 指定あり | 全曜日でそのシフトを禁止 |

選択可能曜日: 月 / 火 / 水 / 木 / 金 / 土 / 日 / 祝 / 土日 / 土日祝

固定メンバーの休日管理もここで行う（例: 小里の土日祝を OFF にしたい場合は禁止設定で土日祝を指定）。

**ソルバーへの影響:**
- 曜日+シフト → `unavailableWeekdayShifts`
- 曜日のみ → `forcedOffDates`（当月の該当日を計算してリスト化）
- シフトのみ → `forbiddenAlwaysShifts`

---

### 5. 区分設定

**目的:** 自動勤務設定や特定日で区分が指定された日に、勤務メンバーの構成条件を課す。

**設定内容:**
- 区分ごとに「属性 + 人数」の条件を複数行登録
- 区分は複数追加可能

**条件の満たし方（OR）:**
自動勤務設定・特定日で複数区分が紐付けられた日は、そのうち**いずれか1つ**の区分条件を満たせばよい。全区分を同時に満たす必要はない。

**ソルバーへの影響:**
`coverageRules` として送信。バックエンドが各日・各区分の OR 条件として追加。

---

### 6. 勤務区分

**目的:** シフトの種類・時間帯・自動割り当て対象かどうかを定義する。

**設定内容:**
- コード（A / C / E など）、時間帯（例: 7:00-16:00）、自動チェックボックス

**自動チェックの意味（重要）:**
- **チェックあり:** 自動作成時にソルバーが自由に割り当て対象にするシフト
- **チェックなし:** ソルバーは使用しない。特定日・固定・手動入力でのみ使われる

自動チェックは勤務区分セクションが保持するステータスであり、自動勤務設定セクションとは別物。

**時間帯重複の自動判定:**
シフト間の休憩が8時間未満になる組み合わせを自動検出し、そのシフトペアを連続日に割り当てないようソルバーに制約を追加する（例: C→A, E→A）。

**ソルバーへの影響:**
`shifts`（全シフト定義）+ `autoShiftCodes`（自動対象コード一覧）+ `requiredTransitionBreaks` として送信。

---

### 7. 属性

**目的:** スタッフに付与できる役職・カテゴリの名称を定義する。

**設定内容:**
- 名称のみのリスト（例: リーダー / サブリーダー / 新人）
- 区分設定で使う属性ラベルの候補になる
- スタッフ設定でメンバーに紐付ける

**ソルバーへの影響:**
`staffAttributes`（メンバー→属性の辞書）として送信。

---

### 8. スタッフ

**目的:** 勤務表に含めるメンバーの登録と属性の割り当て。

**設定内容:**
- 氏名を入力して追加
- 各メンバーに属性（7. で定義したもの）を1つ割り当て可能
- 上下矢印で表示順（=勤務表の行順）を変更可能
- 削除ボタンで除外

**ソルバーへの影響:**
`staff`（メンバー順序付きリスト）として送信。

---

### 9. 基本条件

**目的:** 連勤・連休に関する最低ルールを設定する。

**設定内容:**
- **最大連勤:** 連続して出勤できる最大日数（デフォルト6日）
- **最小連休:** 休みが入る場合は必ずこの日数以上まとまって休む必要がある（デフォルト2日）

**ソルバーへの影響:**
`maxConsecutive` / `minConsecutiveHolidays` として送信。
前月末の勤務状態も引き継いで月初の制約に反映する。

---

### 10. その他条件

**目的:** ソルバーの最適化方向を調整する補助オプション。

**設定内容（チェックボックス）:**
- **連勤中の勤務切替を可能な限り避ける:** 同じシフトが連続するよう優先（例: A-A-A を A-C-A より優先）

ハード制約ではなく目的関数のペナルティとして作用するため、他の条件と競合した場合は無視されることがある。

**ソルバーへの影響:**
`preferSameShiftStreaks` として送信。

---

## 勤務表（右側のグリッド）

- 土日・祝日はヘッダが灰色表示
- 各セルをクリックしてシフトを手動変更可能
- OFF / PAID（有給）/ 特休（特別休暇）は手動入力専用（ソルバーは自動で入れない）
- 右端に勤務日数カウント表示

**自動作成の動作:**
- 「自動作成」ボタンでソルバーに送信する
- **事前に手入力されているセル（PAID・特休・手動シフト等）は絶対厳守**。ソルバーはその割り当てを上書きしない
- 前月の勤務表の末尾状態（最終シフト・連勤日数）を引き継いで、月をまたいだ連勤・連休制約に対応する

**その他操作:**
- 「初期化」ボタンで全員 OFF にリセット
- 月ごとに保存・読み込み可能

## バックエンドが受け取る主要フィールド一覧

| フィールド | 型 | 説明 |
|---|---|---|
| `shifts` | `dict[str, ShiftDefinition]` | 全シフト定義（auto フラグ含む） |
| `weekdayNeed` / `saturdayNeed` / `sundayNeed` / `holidayNeed` | `dict[str, int]` | シフトごと曜日種別の必要人数 |
| `maxConsecutive` | `int` | 最大連勤日数 |
| `minConsecutiveHolidays` | `int` | 最小連休日数 |
| `fixedDateShifts` | `dict[str, dict[str, str]]` | メンバー→日付→固定シフト |
| `unavailableWeekdayShifts` | `dict[str, dict[str, list[str]]]` | 曜日別禁止シフト |
| `forbiddenAlwaysShifts` | `dict[str, list[str]]` | 全曜日禁止シフト |
| `forcedOffDates` | `dict[str, list[int]]` | 強制休日の日付リスト |
| `requiredTransitionBreaks` | `list[[str, str]]` | 連続禁止シフトペア |
| `coverageRules` | `list[dict]` | 区分ルール（OR条件） |
| `staffAttributes` | `dict[str, str]` | メンバー→属性 |
| `dateNeed` | `dict[int, dict[str, int]]` | 特定日の必要人数上書き |
| `holidayDates` | `list[int]` | 当月の祝日一覧 |
| `autoShiftCodes` | `list[str]` | 自動割り当て対象シフトコード一覧 |
| `preferSameShiftStreaks` | `bool` | 同一シフト連続優先 |
