勤務表作成 操作手順書

1. 起動方法
- ShiftRosterBuilder.exe をダブルクリックします。
- 黒い画面が開いたままになりますが、これはアプリ本体のサーバーです。
- ブラウザで http://127.0.0.1:5173 が開きます。
- 黒い画面を閉じるとアプリも終了します。

2. 保存データの場所
- 正式な保存データは ShiftRosterBuilder\data\rosters.json です。
- 保存、呼び出し、前月参照はこの rosters.json を使用します。
- data フォルダがない場合は、初回保存時に自動で作成されます。

3. 既存ブラウザ保存データの初回移行
- 以前の版でブラウザ内に保存されていたデータがある場合、data\rosters.json が空のときだけ初回起動時に移行します。
- 移行後は data\rosters.json を正式な保存データとして扱います。
- 以後の保存、呼び出しは data\rosters.json を使います。

4. 別PCへ持っていく場合
- ShiftRosterBuilder フォルダごとコピーしてください。
- 保存済みデータを持っていく場合は data フォルダも必ず一緒にコピーしてください。
- ShiftRosterBuilder\data\rosters.json が存在していれば、別PCでも同じ保存データを呼び出せます。

5. プログラム更新時の保存データ退避
- 更新前に ShiftRosterBuilder\data フォルダを別の場所へコピーして退避してください。
- 新しい ShiftRosterBuilder フォルダを配置したあと、退避していた data フォルダを新しい ShiftRosterBuilder フォルダ内へ戻してください。
- 最終的に ShiftRosterBuilder\data\rosters.json という配置になっていれば読み込めます。

6. ZIPについて
- ShiftRosterBuilder.zip は、圧縮した時点の ShiftRosterBuilder フォルダをまとめたものです。
- 圧縮時点で data フォルダが存在していれば、保存データもZIPに含まれます。
- 圧縮時点で data フォルダが存在しない場合、ZIPには保存データは含まれません。

7. 注意
- rosters.json を手動編集すると読み込めなくなる可能性があります。
- 編集や更新の前には必ず data フォルダごとコピーしてください。
